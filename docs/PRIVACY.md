# 隐私说明

Git UI Pro 是本地桌面应用。默认情况下，软件只读取和操作用户主动添加的本地 Git 仓库。

## 本地数据

软件可能在本地保存：

1. 用户添加的项目路径。
2. 项目收藏、最近打开、排序等界面偏好。
3. 窗口布局、主题、面板尺寸等本地设置。
4. 用户主动连接的 GitHub、GitLab 或 Gitee 平台账号标识，以及经系统安全存储加密后的访问令牌。
5. 按项目保存的终端命令历史，用于关闭标签或重启软件后继续检索和复用命令。

这些数据用于恢复用户工作区，不会主动上传到 Git UI Pro 作者或第三方服务器。

## Git 数据

软件会通过用户本机 `git` 命令读取：

1. 当前分支和仓库状态。
2. 提交历史、提交信息、作者信息和引用信息。
3. 工作区变更和 diff。
4. remote、ahead、behind 等同步状态。

当用户主动执行 fetch、pull、push 等远程操作时，网络请求由本机 Git 和仓库 remote 配置发起。

## 凭据

Git UI Pro 不保存平台账号密码或 SSH 私钥。Git 命令认证仍依赖用户本机 SSH key、Git Credential Manager 或 credential helper。

当用户在“仓库中心”主动连接 GitHub、GitLab 或 Gitee 账号时，软件会验证访问令牌，并使用 Electron `safeStorage` 提供的操作系统加密能力保存令牌。令牌不会在界面中回显；系统无法提供加密能力时，软件会拒绝保存。移除平台账号会同时删除本地保存的对应令牌。

平台协作功能仅在用户主动刷新、创建、评论、评审或合并 PR/MR 时，将令牌发送到所选远程仓库对应平台的 HTTPS API。软件不会把令牌发送给 Git UI Pro 作者。

终端命令历史只保存在本地配置中，不会上传。用户可以在终端历史面板中明确清空当前项目的记录。

## 日志和反馈

在反馈问题时，请先检查截图、日志和 Git 输出，避免公开：

1. 访问令牌和密码。
2. SSH 私钥。
3. 公司内部仓库地址。
4. 不希望公开的本地路径或提交内容。
